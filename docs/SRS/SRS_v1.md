#Ingreso de datos
El sistema debe permitir imgresar un usuario y contraseña.

#Credenciales
El sistema debe verificar los datos ingresados con los datos almacenados en la base de datos.

#Contraseña
El sistema debe permitir el restablecer una contraseña olvidada a través de un enlace al email registrado.

#Bloqueo
El sistema debe bloquear el acceso de manera temporal después de un número determinado de intentos fallidos de ingreso.

#Cifrado
La transmición de datos se la debe realizar a través de canales cifrados mediante protocolos seguros.

#Tiempo de respuesta
El acceso a la plataforma no debe superar los 3 segundos en condiciones normales.

#Compatibilidad
La interfaz de acceso debe operar correctamente en los principales navegadores y mantener la misma visualización.

#Concurrencia
El módulo de login debe soportar solicitudes de manera simultanea sin que esto degrade el servicio.
